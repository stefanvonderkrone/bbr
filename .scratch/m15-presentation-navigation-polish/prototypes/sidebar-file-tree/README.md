# PROTOTYPE — Sidebar File Tree

Three variants of the M15 Sidebar File Tree, switchable with `?variant=A`,
`?variant=B`, or `?variant=C`.

This is throwaway UI used to decide the interaction contract. It is not an M15
implementation.

Run from the repository root:

```sh
python3 -m http.server 4173 --directory .scratch/m15-presentation-navigation-polish/prototypes/sidebar-file-tree
```

Then open <http://127.0.0.1:4173/?variant=A>.
