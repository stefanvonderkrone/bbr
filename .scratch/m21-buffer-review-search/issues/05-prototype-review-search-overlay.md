# Prototype Review Search Overlay

## Question

What Review Search Overlay lets the reviewer query, compare, preview, and select streamed occurrences without losing context?

Prototype result rows with path, version, line, column, and snippets. Prototype the larger preview with every query hit highlighted. Cover loading, partial failure, binary and unavailable versions, no matches, reordered streamed results, long paths, long Lines, and narrow terminals. Define keyboard and mouse parity through Actions.
