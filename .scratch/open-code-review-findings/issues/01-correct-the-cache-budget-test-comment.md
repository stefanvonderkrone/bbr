## Problem


## Proposal

Rewrite the comment so that it explains the file count through the current limit, or delete the part about an eighth of the Files.

Not stale on `main`. Commit `8cb4b75e` ("tui: let a known small Review evict while Review Search scans run") added the floor `@min(far_over_budget_floor, bytes / 8)` to `Storage.cachePressure`, where `bytes` is the sum of the known File bytes.
